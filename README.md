# 光的记忆

一束光如何记录世界。

围绕 Gabor 同轴全息的互动科普学习作品。此仓库以第6版网站内容为基础，于2026-10-19微调学习顺序，包含网页、题库、实验图片、三维模型渲染图和完整教学视频的分段副本。

## 学习路径

点亮光源，从无字幕针段三维样品图引出问题，再进入“点亮、遇见、留下”三站原理探索，通过理想化单点散射模型理解干涉。观看完整微课后，进入独立的读图讨论（`#discussion`），首次完整展示两幅真实实验图像，思考同一特征、尺度换算条件以及图像比较与重建的区别；随后阅读知识展签并完成练习。题目提供逐项解释和错题回访。

本页练习包含固定基础四题及50道随机题源。50题分为微课核心35题、知识补充11题、明确拓展4题；每轮随机十题同时满足来源7/2/1、难度4/4/2，轮内不重复。外部完整题库为独立练习资源。

此次学习路径微调未改变题干、选项、答案、解析、来源和难度；Q37、Q38、Q39、Q43、Q44的回访随读图区移至视频后讨论。

## 本地运行

本项目为静态网站，无需安装前端依赖或执行构建。请通过HTTP静态服务器访问，以便浏览器正常读取题库和视频；直接双击HTML可能受到浏览器本地文件限制。

如已安装Python，可在仓库目录运行：

```sh
python -m http.server 8000
```

然后访问 http://localhost:8000/ 。

## 文件

- `index.html`：作品入口与页面结构。
- `app.js`：探索、播放器、答题反馈及回访。
- `quiz-bank.json`、`quiz-sampler.js`：50题数据与双配额随机抽题。
- `styles.css`、`apparatus.css`、`refinements.css`：页面样式。
- `apparatus-*.png`、`experiment-*.jpg`：装置渲染与真实实验图像。
- `sample-model.png`：原样采用建模 `pictures/14.png` 的无字幕针段渲染图，用于认识样品，明确为三维示意；不是实物照片或测量数据。前部不重复展示实验采集图像。
- `media/lesson-00.mp4` 至 `lesson-08.mp4`：原微课的连续播放分段。

原教学视频内容与实验图片保持原样。干涉互动为定性教学模型，不对应真实绣花针图样的定量预测。网页不宣称已完成相位恢复、三维形貌重建或测量精度验证。

三站光路图展示扩束准直后的宽照明覆盖小针段，参考光由针段投影外平行直透，物光波前只在下游示意；两者在同一记录面重叠。尺寸和条纹不按实际比例。实验图红圈仅引导观察同侧明暗过渡，不用于计算位移。

知识库、外部完整题库及拓展参考链接需要联网。第6版已记录桌面和390像素宽度下的流程检查；这些历史记录不代替本次学习路径调整的交互验收。手机真机与Safari仍未验证。
